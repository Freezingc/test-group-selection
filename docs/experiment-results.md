## 统计方法与 11/11 谬误检查

统计单位是题目，使用 seed=20261019 的 10,000 次整题配对 percentile bootstrap。随机分组先在每题平均全部 20 个种子，再重采样题目。所有空候选池和失败候选照原规则保留；比较区间未作多重校正，全部解读为探索性描述。若所有观测配对差皆为零，经验 bootstrap 会退化成 [0,0]，不能证明总体差异为零或方法等效。

| 谬误类型 | 本次处理与限制 |
|---|---|
| Simpson's paradox | 五个 selector 分别报告；E0/E1 分开，没有合并跨数据集效果。 |
| Ecological fallacy | 不将候选、矩阵单元或种子作为独立题目。 |
| Berkson's paradox | 以固定 hash 选题；剩余可挽救题／个案子集只供描述，不代表全体盛行率。 |
| Collider bias | 不从条件化于原选错误或正确池的子集推导来源依赖因果。 |
| Base-rate neglect | 同时列完整 N、候选池覆盖、原选准确率、gain/loss 与救援上限。 |
| Regression to the mean | 没有重抽极端题后宣称改善；E0 不并入 E1。 |
| Survivorship bias | 解析／截断／执行失败有记录；未按隐藏结果排除题目。 |
| Look-elsewhere effect | 报全部五 selector 与 20 种子；未以最佳一列作确认性结论。 |
| Garden of forking paths | E1 配置固定并留下改动记录；不将开发探索称为正式预注册确认。 |
| Correlation versus causation | 同矩阵重新分组衡量算法信息增量，不是生成错误相关性的因果干预。 |
| Reverse causality | 不由 winner 翻转反推某来源组必然错误或存在共享误解。 |

## 解读边界

候选覆盖与 U 是完美集合内选择的潜力，不能解读为真实审核收益。两个集合的 coverage 差也不是它们真实审核准确率差的一般上界。E2 需要另定固定审核器、展示方式、回退规则与相同调用／token 预算，并报错改对、对改错和净增益。

本次只有单模型、单候选池 seed 设计与 MBPP+ 开发子集；没有跨模型／数据集、污染控制或完整近邻复现。公开任务可能与预训练重叠；通过有限官方测试不构成语义正确性证明。可见 stdlib/0.5 秒环境与官方 hidden 依赖／时限不同，需检查是否由环境差异驱动个案，不可自动归因于测试语义偏差。

140 题探索不足以可靠确认或否定 2 个百分点的小差异。小样本区间包含零，不等于没有作用；少量有利案例也不足以建立来源分组优势。没有正式预注册、作者阅读认证、盲审或跨模型独立验证。

## 研究决策与后续条件

H1 在本协议下成立为描述性观察：强基础选择器仍有11题“原选错、池内正确”。H2 尚未建立：来源扰动在五列均低于行为多样性点估计；四列也低于随机均值，group_rep 的随机增量仅 +0.21 pp、95% CI [−0.43, +1.00]。H3 未测，H4 仅有个案机制线索。这不足以支持扩大到昂贵审核或追加复杂模块，也不能宣称已证明所有成对审核无效。

目前决策为保存本轮负面／混合证据，暂不启动 E2 或消耗保留集。若继续，先以新版本协议共同修正格式抽取、厘清可见／隐藏依赖及输入域差异，再用新的生成种子做开发重复，完整保留与本版的差异。不能事后只清洗本轮有利候选、删除失败题或更换主比较。只有再观察到简单对照不能解释的候选增量，才固定审核器、预算和回退规则进入 E2；若转向“候选更易被审核”，需另写假设与评估，不能改写本次 H2。
